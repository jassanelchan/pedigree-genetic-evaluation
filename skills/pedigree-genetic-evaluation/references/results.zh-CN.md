# 结果、标准误与图表

结果模块使用已经验证的质控后记录和最终模型组分，不筛选动物、不更改模型，也不修复估计失败。每个随机项有唯一组分名称和科学角色，角色为 `additive`、`litter`、`pe` 或 `iid`，残差另列。例如 `sow_pe` 是组分名称，其声明角色为 `pe`。名称与角色不能从软件效应编号或打印标题推断。原有快捷模型保留旧的结果标签，同时记录来源组分 `shared`。

## 遗传参数

性状 t 的模型尺度表型方差为：

`Vp[t] = additive[t,t] + sum(random_term[t,t]) + residual[t,t]`

求和包括全部适用于 t 的额外独立随机项，不适用的行列为结构性零。这是扣除指定固定效应后的方差，不是原始样本方差。通常报告的群体参数使用加性遗传方差，不将每头动物各自的 `1 + F` 乘入该参数。

- 狭义遗传力：`h2[t] = additive[t,t] / Vp[t]`。
- 仅对含永久环境效应的性状报告重复力：`(additive[t,t] + 全部适用 PE 方差之和) / Vp[t]`。只有角色为 `pe` 的项进入分子，共同窝和 `iid` 项仍计入分母。
- 对每对不同性状 s,t 报告加性遗传相关：`additive[s,t] / sqrt(additive[s,s] * additive[t,t])`。
- 所有方差组分、性状间协方差、单位和标准误列入同一张表。比例和相关系数没有量纲。

[三性状示例](example/multitrait-project.json)中，两个生长性状的 Vp=VA+Vbirth_litter+VE，TNB 的 Vp=VA+Vsow_pe+VE，只有 TNB 报告重复力。完整加性矩阵连接三个性状；共同窝矩阵没有 TNB 方差，PE 矩阵没有生长性状方差。遗传参数表同时记录 `component` 和科学 `role`，可区分多个命名环境项。

总方差为 0 时，遗传力和重复力未定义；加性方差对角元为 0 时，相应遗传相关未定义。较小或边界估计保留并注明，不用熟悉的文献值替换。最终矩阵出现非有限值、不对称，或明显不满足半正定性时，验证失败，不生成看似正常的结果报告。

## 标准误

函数的标准误采用解析 delta 法：

`SE(f) = sqrt(gradient(f)' %*% param_cov %*% gradient(f))`。

`param_meta` 必须按完整采样协方差矩阵的准确行列顺序描述每个已估协方差参数。其 `role` 字段为唯一组分键，科学角色由模型注册表提供，性状索引采用全局顺序。原生因子局部索引在使用前完成映射，也支持非连续适用子集。不预设效应顺序；参数可以重新排序，但元数据与采样协方差必须一起调整。受约束的零和不适用的结构性零均不属于待估参数集合。

对遗传力 A/P，加性方差的偏导数为 `(P-A)/P^2`，其他每个方差对角元的偏导数为 `-A/P^2`。对重复力 N/P，加性和每个适用永久环境方差的偏导数均为 `(P-N)/P^2`，其他方差对角元为 `-N/P^2`。对遗传相关 r，协方差的偏导数为 `1/sqrt(A_s*A_t)`，两个加性方差的偏导数为 `-r/(2*A_s)` 和 `-r/(2*A_t)`。

计算需要包括非对角项在内的完整采样协方差，不能用相互独立的组分 SE 替代。采样协方差缺失、不完整、不对称或不满足半正定性时，派生参数的 SE 留空并说明原因。经过验证的原生组分 SE 仍可保留，但不能补足遗传力或相关 SE 所需的参数协方差。边界处的 delta SE 为渐近近似，会明确标注。与软件 Monte Carlo SE 存在小差别可能来自计算方法不同。

## 可靠性

可靠性为可选结果，只在 SEP、加性遗传方差及关系矩阵对角元所对应的 F 均经验证时计算：

`REL = 1 - SEP^2 / ((1 + F) * additive[t,t])`。

SEP 必须是预测误差的标准差，不是方差组分的采样标准误。F 必须与拟合时的关系矩阵约定一致，缺失 F 不自动置为 0。SEP 为负、F 无效、加性方差为 0，或 PEV 大于相应模型方差时，REL 留空并附状态说明，不将异常值强行截在 [0,1]。这一条件可靠性不包括估计方差组分带来的不确定性。

## 年度汇总

默认 `event_year` 按观测或生产事件分组：生长性状使用测定年份，产仔数使用分娩年份。可选的 `birth_year` 汇总回答的是出生世代间的变化。两种年份口径在表和文件名中明确区分，不混用。

混合单次/重复记录设计中，`record_filter` 定义每个性状所属的事件。只有属于该性状且被保留的行进入年度分组，也包括该性状缺失、但另一个性状仍有观测的适用行。因此，母猪的分娩日期不会为生长性状新增年度 EBV 记录。事件归属与观测是否通过质控是两个不同概念。

每年、每个性状分别统计：

- 表型均值和标准差使用该性状有效观测。重复记录按记录计数，因此每条保留的分娩记录提供一个产仔数观测。
- 平均 EBV 在适用事件行内每头动物每年最多计入一次，包括该性状缺失、但另一个性状有观测的动物。同一母猪的 TNB 可以进入多个分娩年份，每年各计一次。
- `n_records`、`n_animals`、`n_phenotyped` 和 `n_ebv` 分别报告。年度 EBV 均值不按每头母猪的分娩次数加权。
- 年份无效或不可用的记录从该年度汇总中排除并说明。同一动物出现矛盾的出生年份时，验证失败。

至少有 3 个有效年度均值才拟合线性趋势。拟合采用年度均值对年份的普通非加权回归，输出斜率、斜率标准误、R²、有效年份数和“性状单位/年”。仅有两年时保留均值，不报告拟合趋势。回归不改变 EBV，也不重新估计模型；修改年度口径只需要重新处理结果。

## 交付与显示格式

`ge_export_results` 为每项分析生成 `results.xlsx`、`EBV.csv`、质控直方图，以及表型/遗传进展 PNG，并返回文件路径及遗传参数、年度均值、趋势表，供项目总表使用。

- 数值单元格保留完整精度。Excel 显示时，记录数用整数，描述性统计保留 2 位小数，方差组分、遗传力等遗传参数保留 3 位小数。
- 均值为正时，`CV_percent = 100 * SD / mean`。均值为 0 或负值时，CV 未定义，不能按普通正百分数报告。
- CSV 使用 UTF-8 BOM。原始 ID 为字符串，工作簿保留前导零；若 Excel 自动转换 CSV 的 ID 列，应按文本导入。
- 质控前后直方图使用相同的分箱和坐标轴。可通过 `ctx$raw_data` 或 `ctx$qc_before` 提供质控前的数值列 `y1 ... yN`。若无法取得这些数据，则只导出保留值的分布，并说明未能生成质控前图。
- 趋势图标题仅为 `表型进展` 和 `遗传进展`。坐标轴标明年份口径、性状与单位；实线连接年度均值，虚线表示年度拟合，不添加底部说明。超过四个性状时，每张 PNG 最多放四个性状，文件名标注性状范围。
- 性状无有效值时显示明确的空面板，不构造虚假分布。标签使用用户提供的性状名称与单位。
- 用户另行提供描述性统计表时，记录数应为整数列，CV 列应明确标注百分比。导出器不会在缺少定义时自行把用户提供的 CV 小数解释为百分数。

EBV 超过工作表行数上限时，CSV 中仍保留全部结果，不为了放入 Excel 而截断。该模块不覆盖原始输入或模型输出。
